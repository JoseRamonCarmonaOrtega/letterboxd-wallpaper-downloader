# 🎬 Letterboxd Wallpaper Downloader

Aplicación de escritorio gráfica para descargar fondos de pantalla en alta resolución (hasta 4K) basados en tus exportaciones CSV de Letterboxd.

## 🚀 Cómo usar (Sin instalar Python)

1. Ve a la sección **Releases** o **Actions** en este repositorio.
2. Descarga el ejecutable `LetterboxdWallpaperDownloader.exe`.
3. Haz doble clic en el archivo para abrir la aplicación.
4. Selecciona tu archivo `.csv` e introduce tu API Key de [TMDb](https://www.themoviedb.org/).
5. Haz clic en **Comenzar Descarga**.
